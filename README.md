# R6 Tools

레인보우 식스 시즈(Rainbow Six Siege) 인게임 메뉴에서 직접 바꿀 수 없는 `GameSettings.ini` 세부 설정(데이터센터 서버 변경, 고급 감도 멀티플라이어)과 다계정 설정 동기화, 리플레이 백업 및 캐시 정리를 한곳에서 관리하는 Windows 유틸리티입니다.

메모리 접근이나 오버레이 후킹 없이 유비소프트가 허용하는 로컬 설정 파일(`GameSettings.ini`) 수정 및 정적 파일 관리 방식으로만 동작합니다.

## 상세 기능

### 1. 인게임 설정 제어 (`GameSettings.ini`)
* **데이터센터 변경 및 Ping 확인**
  * 일본 서부, 동남아시아, 동아시아, 미국(서부/중부/동부), 유럽(서유럽/북유럽), 호주, 브라질 등 11개 글로벌 데이터센터를 원클릭으로 변경합니다.
  * 각 리전 엔드포인트(TCP Port 443)와의 통신 지연 시간을 실시간으로 측정해 최적의 서버를 추천하며, 기본값(자동 접속 모드) 복원도 지원합니다.
* **고급 감도 멀티플라이어 미세 조정**
  * **마우스 감도 멀티플라이어 (`MouseSensitivityMultiplierUnit`)**:
    * 기본값(`0.020000`), 정밀 10배(`0.002230`) 원클릭 프리셋 및 소수점 6자리 직접 입력을 지원합니다.
    * 정밀 멀티플라이어를 적용하면 인게임 1단위 감도가 기존의 1/10 수준으로 세분화되어 초미세 감도 튜닝이 가능합니다.
  * **1.0x 조준 감도 멀티플라이어 (`XFactorAiming`)**:
    * 기본값(`0.020000`), 1:1 매칭(`0.083333`) 원클릭 프리셋 및 직접 입력을 지원합니다.
    * `0.083333` 설정 시 지향사격과 1.0x 무배율 조준 감도가 1:1로 정확히 일치하여 에임 일관성을 높입니다.
  * **소수점 포맷 및 안전 저장**:
    * 윈도우 OS 언어/국가 설정과 관계없이 항상 표준 소수점(`.`) 포맷이 유지되도록 처리되었습니다(`InvariantCulture` 적용).

### 2. 다계정(UUID) 관리 및 백업
* **계정 별칭(Alias) 지정 및 선택 동기화**
  * `내 문서\My Games\Rainbow Six - Siege` 하위의 32자리 UUID 폴더마다 '본계정', '부계정1' 등 원하는 별칭을 부여하고 인라인으로 간편하게 수정/저장할 수 있습니다.
  * 기준 계정의 설정 중 원하는 영역(조작/감도, 조준기 색상, 디스플레이, 오디오, 그래픽 품질)만 골라 다른 계정에 덮어쓰거나 병합할 수 있습니다. 동기화 작업 전 대상 파일은 자동으로 `.bak` 백업됩니다.
* **시즌 패치 대비 프리셋 보관 및 변경점(Diff) 확인**
  * 대규모 업데이트나 클라우드 동기화 오류로 설정이 초기화되는 상황에 대비해 현재 설정을 이름별 프리셋으로 영구 보관하고 언제든 복원합니다.
  * 외부 프리셋 파일 불러오기 및 내보내기(Export/Import)를 지원합니다.
  * 백업본과 현재 `GameSettings.ini` 파일의 값을 섹션 및 키 단위로 정밀 비교하여 변경된 항목을 한눈에 보여줍니다.
  * 파일이 `읽기 전용(ReadOnly)` 상태여도 프로그램에서 설정을 저장할 때만 일시적으로 잠금을 해제했다가 안전하게 복구합니다.

### 3. 시스템 및 파일 관리
* **게임 실행 감지 및 바로 실행**
  * 레식 클라이언트(`RainbowSix.exe`, `RainbowSix_BE.exe`, `RainbowSix_Vulkan.exe`)가 실행 중일 때는 파일 충돌 및 설정 롤백을 막기 위해 모든 저장 버튼이 자동으로 비활성화(안전 잠금)됩니다.
  * 설정 적용 후 프로그램 상단/하단에서 Steam(`steam://rungameid/359550`) 또는 Ubisoft Connect(`uplay://launch/635/0`) 프로토콜을 통해 게임을 원클릭으로 바로 실행할 수 있습니다.
* **매치 리플레이 영구 보관 및 캐시 정리**
  * 최근 12경기만 유지되고 시즌 패치 시 삭제되는 `MatchReplay` 폴더를 별도 보관소(`ReplayArchive`)로 안전하게 백업 및 복원합니다.
  * 각 리플레이 폴더의 생성 일시와 실사용 용량을 확인하고 Windows 탐색기에서 바로 열람할 수 있습니다.
  * 스터터링(프레임 드랍)이나 클라우드 동기화 무한 로딩 오류 원인이 되는 DirectX 셰이더 캐시(`D3DSCache`, `DXCache`)와 유비소프트 런처 캐시(`spool`, `cache`)를 원클릭으로 감지 및 정리합니다.

### 4. UI 및 사용자 경험
* **토스 디자인 시스템 (TDS) 기반 UI**: 깔끔한 타이포그래피와 모던한 카드 뷰 레이아웃을 제공합니다.
* **다크 모드 & 라이트 모드**: 헤더 우측 토글 버튼을 통해 라이트 테마와 TDS 다크 테마를 실시간으로 전환할 수 있습니다.
* **다국어 (i18n) 지원**: 한국어와 영어(English)를 실시간으로 원클릭 전환할 수 있습니다.
* **환경설정 자동 저장**: 사용자가 선택한 언어 및 테마 설정은 `app_settings.json`(권한 부족 시 `%APPDATA%\R6Tools`)에 자동 저장되어 재실행 시 유지됩니다.

## 실행 및 빌드 방법

### 요구 사항
* **OS**: Windows 10 (1809 이상) / Windows 11 (x64)
* 별도의 .NET 런타임 설치 없이 단일 `.exe` 파일로 바로 실행할 수 있습니다.

### 직접 빌드하기
Visual Studio 2022 또는 `.NET 8.0 SDK`가 설치된 환경에서 아래 명령어로 단일 실행 파일을 생성할 수 있습니다.

```powershell
dotnet publish -c Release -o ./publish
```
* 빌드 경로: `publish\R6Tools.exe`

## 기술 스택
* **Language & Runtime**: C# 12, .NET 8.0 (WPF)
* **UI & Styling**: WPF-UI 3.0 (Fluent Design), Toss Design System(TDS) 스타일 토큰
* **Architecture**: MVVM (`CommunityToolkit.Mvvm 8.2`)

## 주의사항 및 면책 조항
* 이 프로그램은 게임 프로세스 메모리에 접근하거나 DLL 인젝션, 입력 후킹 등을 일체 사용하지 않으며, 로컬 문서 폴더(`My Games\Rainbow Six - Siege`) 및 캐시 폴더 내의 정적 파일만 다룹니다.
* 본 소프트웨어는 Ubisoft의 공식 프로그램이 아니며, 사용자 편의를 위해 제작된 비공식 오픈소스 유틸리티입니다.
